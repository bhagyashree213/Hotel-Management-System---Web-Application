# 🏨 Luxury Stay Hotel — Web Application

A multi-page hotel management web application built with **HTML**, **CSS**, and **JavaScript**. It features room browsing, online booking, a photo gallery, and contact information for **Luxury Stay Hotel**, Pune.

---

## 🌐 Live Demo

> Open `index.html` in your browser to explore the website locally.

## 📄 Pages

| Page | File | Description |
|------|------|-------------|
| 🏠 Home | `index.html` | Landing page with announcements, latest offers, upcoming events, guest notices, hotel services, about us, and certifications |
| 🛏️ Rooms & Suites | `rooms-suites.html` | Listing of all room types with descriptions and pricing |
| 📅 Book Now | `book-now.html` | Online booking form with room selection, date picker, guest count, real-time price calculation, and payment method selection |

---

## ✨ Features

- **Responsive Navigation** — Consistent header and footer across all pages
- **Hotel Announcements** — Scrolling notice bar on the home page
- **Latest Offers** — Scrolling promotional offers section
- **Upcoming Events** — List of hotel events with dates
- **Online Booking Form** with:
  - Hotel search with autocomplete suggestions
  - Room type selector (7 room types)
  - Check-in / Check-out date picker
  - **Dynamic price calculator** (price per night × number of nights)
  - Payment method selector (Credit Card, Debit Card, PayPal, Net Banking)
  - Card details form (shown only for card payments)
  - Booking confirmation alert with guest's email
- **Photo Gallery** — 9-image grid of hotel photos
- **Contact Page** — Full address, phone, and email with clickable links

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bhagyashree213/Hotel-Management-System---Web-Application.git
   cd Hotel-Management-System---Web-Application
   ```

2. **Open in browser:**
   - Simply open `index.html` in any modern web browser
   - No server setup or dependencies required — it's pure HTML/CSS/JS

3. **Navigate the site:**
   - Use the top navigation bar to explore all pages
   - Try the booking form on the **Book Now** page

## 📝 Notes

- This is a **front-end only** project. The booking form displays a confirmation alert but does not submit data to a real backend server.
- Images are stored locally in the project folder. Ensure all image files are present for correct display.
- The hotel search autocomplete uses a hard-coded list of sample hotels for demonstration purposes.
